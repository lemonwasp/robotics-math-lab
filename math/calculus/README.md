# Calculus — intuition to motion

**Status: planned.** No worked solutions are published yet.

- Geometry: circle equation, tangent lines, ellipse/hyperbola, parametric representation.
- Trigonometry: unit circle, radians, sine/cosine, angle addition, periodicity.
- Limits and derivatives: rate of change, chain rule, implicit differentiation, second derivatives.
- Integrals: accumulation, substitution, integration by parts, the fundamental theorem, introductory multivariable integrals.
- Multivariable calculus: partial derivative, Jacobian, gradient, Hessian, local linearization.

**Robotics:** tip position → velocity → acceleration and sensitivity. **AI:** chain rule → backpropagation; gradient → optimization.

First learning target: investigate the relationship between a rotating line segment, the unit circle, and differentiation. Develop an explanation independently before considering code.

# Robotics Math Lab — 나의 수학·물리·로보틱스·AI 학습 기록

이 저장소는 **내가 직접 공부하고, 이해하고, 문제를 풀고, 응용한 과정을 기록하기 위한 공간**이다.

[English README](README.md) · [9개월 세부 학습 계획](docs/roadmap.md) · [학습 방식](docs/study-method.md) · [미풀이 과제](tasks/README.md)

## 목적

- 수학·물리 원리를 파인만식으로 이해하고 설명하기
- 원의 방정식, 삼각함수, 미분·적분에서 출발해 로보틱스·AI로 연결하기
- 고전부터 현대까지 양질의 한국·일본·미국·유럽 문제로 사고력 확장하기
- IBUKI와 같은 센서·엣지 AI 프로젝트에 적용할 기초 쌓기
- 장기적으로 로보틱스 대학원 진학과 피지컬 AI 개발에 활용하기

## 학습 단계

1. **개념 질문:** 왜 그런 정의와 성질이 생기는가?
2. **스스로 풀이:** 직접 시도하고, 막히면 정답보다 힌트를 먼저 확인한다.
3. **오류 분석:** 풀이의 가정·단위·논리와 반례를 살펴본다.
4. **응용 탐색:** 로봇의 운동, 물리 센서, AI 학습과 연결해 본다.
5. **직접 구현:** 개념을 이해한 뒤 필요할 때만 실험 코드를 작성한다.
6. **검증·기록:** 본인이 얻은 계산·그래프·테스트 결과만 완료로 표시한다.

## 현재 상태

- 학습 로드맵과 세부 목차: **초안 작성**
- 문제 및 응용 과제: **미풀이**
- Python 구현·실험 결과: **미착수**
- 테스트 결과: **없음**

**중요:** 문제의 답, 해설, 완성 코드, 실험 결과를 미리 만들어 넣지 않는다. 학습하기 위한 질문과 계획을 먼저 정리하고, 실제로 공부한 내용이 생길 때만 추가한다.
